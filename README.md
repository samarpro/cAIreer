# A2A Hire

A2A Hire is a job-search assistant that automates repetitive application work while keeping the job seeker in control of how they are represented.

## Local development

Requirements:

- Node.js 20.9 or newer
- pnpm 11.13.1

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Run the shared quality gate before committing:

```bash
pnpm check
pnpm build
```

The architecture and build order live in [`TECH-MAP.md`](TECH-MAP.md).
