# Product vision

cAIreer helps ambitious students and early-career professionals reduce repetitive job-search work without surrendering control over how they are represented.

The target user already uses AI for resumes and applications. Their problem is not access to generated text. They repeatedly reformat resumes, rewrite summaries, rearrange experience, inspect job listings, and move information between systems. They want automation, but they still care about confidence, maturity, tone, factual accuracy, and the stories chosen to represent them.

The first distinct interaction is a selectable resume. The system identifies visible regions on the uploaded document. The user selects a region, opens a compact chat, requests a change, reviews the proposed result, and decides whether to accept it. The system must make focused changes without silently rewriting the rest of the resume.

Later browser use helps inspect and navigate job listings. It should be fast and cheap for routine work, show its actions, and ask for approval before a consequential external action.

Employer-side agent negotiation is a possible later product. It is not required to prove the job-seeker workflow.
